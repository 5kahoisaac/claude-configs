# claude-configs

My global Claude Code config, restorable on any machine with one command:

```bash
curl -fsSL https://raw.githubusercontent.com/5kahoisaac/claude-configs/main/install.sh | bash
```

Or from a checkout: `./install.sh`. Safe to re-run. Anything it overwrites is
backed up to `~/.claude/backups/claude-configs-<timestamp>/`.

Requires `git` and `python3`. Installs Claude Code via the native installer if
`claude` is missing. Honors `CLAUDE_CONFIG_DIR`; `CLAUDE_CONFIGS_REF` picks a
branch/tag other than `main`.

## What is tracked (`claude/`)

| Source                                      | Installed as                     | How                                  |
|---------------------------------------------|----------------------------------|--------------------------------------|
| `CLAUDE.md`                                 | `~/.claude/CLAUDE.md`            | copied                               |
| `settings.json`                             | `~/.claude/settings.json`        | deep-merged; other keys kept         |
| `settings.json` → `extraKnownMarketplaces`  | plugin marketplaces              | `claude plugin marketplace add`      |
| `settings.json` → `enabledPlugins`          | plugins                          | `claude plugin install --scope user` |
| `mcp.json`                                  | user-scope MCP servers           | `claude mcp add-json -s user`        |
| `skills/<mod>/`                             | `~/.claude/skills/<mod>/` (mods) | copied                               |

`settings.json` is the single source of truth for marketplaces and plugins:
add a marketplace or plugin there and re-run.

## Deliberately not tracked

Generated by tools on each machine, so copying them here would only drift:

- **ECC plugin output** — skills, agents, commands, hooks come from the `ecc`
  plugin. ECC rules can't ship in a plugin, so `install.sh` copies them from
  the ECC marketplace clone into `~/.claude/rules/ecc/`.
- **`npx skills` symlinks** — `~/.claude/skills/*` links into `~/.agents/skills`,
  managed by the skills CLI and its `~/.agents/.skill-lock.json`.
- **Orca hooks + `statusLine`** — written into `settings.json` by the Orca app.
  The merge keeps them on machines that have them.
- **RTK** — `rtk init -g` writes its own hook and `RTK.md`.
- **claude.ai synced skills**, plugin caches, sessions, history, credentials.

## Updating

Edit files under `claude/`, commit, push. On other machines, re-run the curl line.
